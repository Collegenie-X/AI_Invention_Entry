## 2. 발명 프로세스 — 반복하는 고리

```mermaid
flowchart LR
    A["① 발견<br><small>무엇이 불편한가</small>"] --> B["② 정의<br><small>무엇과 무엇을 구분?</small>"]
    B --> C["③ 설계<br><small>보고·판단하고·반응</small>"]
    C --> D["④ 제작<br><small>만든다</small>"]
    D --> E["⑤ 테스트<br><small>언제 틀리나?</small>"]
    E --> F["⑥ 개선<br><small>원인을 찾아 고친다</small>"]
    F -- "2~3회전 반복" --> E

    classDef core fill:#fff3cd,stroke:#d39e00,stroke-width:2px;
    class E,F core;
```

> 대부분의 수업은 ④에서 끝난다. 이 수업은 **⑤↔⑥ 구간에 6차시 중 2.5차시**를 쓴다.

## 5. 6차시 전체 지도

```mermaid
flowchart TD
    T1["<b>1차시 — 완성품을 만난다</b><br>① 발견 · P·R<br>예측 기록지 · 팀 주제 1개"]
    T2["<b>2차시 — 컴퓨터 비전을 뜯어본다</b><br>② 정의 · I<br>실험 A·B·C · 클래스 확정"]
    T3["<b>3차시 — 피지컬 컴퓨팅을 뜯어본다</b><br>③ 설계 · I<br>실험 D·E·F · 동작 설계표"]
    T4["<b>4차시 — 우리 것으로 고친다</b><br>④ 제작1 · M Modify<br>모델 학습 · 코드 v0.1"]
    T5["<b>5차시 — 붙이고 테스트한다</b><br>④ 제작2 · M Make · ⑤ 테스트<br>코드 v0.2 · 실패 10건 이상"]
    T6["<b>6차시 — 고친다</b><br>⑥ 개선 2~3회전<br>코드 v0.3 · 개선 이력표"]

    T1 --> T2 --> T3 --> T4 --> T5 --> T6

    T2 -. "실험 C 조건 순서" .-> T4
    T3 -. "실험 E 지우기 위치" .-> T5
    T2 -. "실험 B 신뢰도" .-> T6
    T5 -. "같은 테스트 12개 재실행" .-> T6

    classDef must fill:#ffe3e3,stroke:#c92a2a,stroke-width:2px;
    class T2,T5,T6 must;
```

> 붉은 칸(2차시 실험 C · 5차시 테스트 12개 · 6차시 전체)은 **시간이 부족해도 절대 줄이지 않는다.**

## 7. 발명품 동작 순서도 (3차시 산출물)

```mermaid
flowchart TD
    S(["시작"]) --> CAM["카메라 보기"]
    CAM --> CLS["학습한 모델로 분류"]
    CLS --> Q1{"플라스틱?"}
    Q1 -- 예 --> A1["LED 하트 + '도' 음<br>1초 후 지움"]
    Q1 -- 아니오 --> Q2{"종이?"}
    Q2 -- 예 --> A2["LED 네모 + '미' 음<br>1초 후 지움"]
    Q2 -- 아니오 --> Q3{"캔?"}
    Q3 -- 예 --> A3["LED 삼각형 + '솔' 음<br>1초 후 지움"]
    Q3 -- 아니오 --> A4["✕ 모르겠음<br>다시 보여주세요"]

    A1 --> CAM
    A2 --> CAM
    A3 --> CAM
    A4 --> CAM

    classDef unknown fill:#f1f3f5,stroke:#868e96;

```
