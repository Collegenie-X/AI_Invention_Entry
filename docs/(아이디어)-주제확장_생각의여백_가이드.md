# 무엇을 구분하며 살아가는가
## 주제 확장 가이드 — 아이들에게 생각할 여백을 주기 위한 재설계

> 『만들면서 배우는 AI 발명 프로젝트』 6차시 커리큘럼의 **주제 영역 확장판**
> 대상 : 초등 5학년 3인 1팀

# 1. 왜 다시 짜는가

## 1.1 '분리수거 도우미'의 한계

주제를 하나로 정해 주면 수업은 매끄럽게 굴러갑니다. 대신 아이들은 **발명가가 아니라 실행자**가 됩니다. 정해진 답을 향해 정해진 절차를 밟는 것은 프로젝트가 아니라 실습입니다.

더 큰 문제는 따로 있습니다. 분리수거는 **이미 답이 정해진 문제**입니다. 페트병은 플라스틱이고 캔은 캔입니다. 여기에는 아이가 생각할 여백이 없습니다. 정답이 밖에 있으니까요.

## 1.2 그런데 진짜 문제는 이것입니다

```
   AI를 만든다는 것은
   "무엇과 무엇을 구분할지" 를 정하는 일입니다.

   그 경계는 세상에 있는 것이 아니라
   우리가 긋는 것입니다.
```

이 사실이 이 수업이 다룰 수 있는 가장 값진 것입니다. 그리고 이것은 기술 문제가 아니라 **사회학·심리학·철학의 문제**입니다.

아이들이 AI에게 "이건 A고 저건 B야"라고 가르치는 순간, 아이들은 **범주를 만드는 사람**이 됩니다. 그 권한을 느끼게 하는 것이 이 수업의 핵심이 되어야 합니다.

## 1.3 그래서 이렇게 바꿉니다

| | 기존 | 확장 |
|---|---|---|
| **주제** | 분리수거 도우미 (교사가 지정) | **"우리 삶에서 구분이 필요한 순간"** (5개 갈래 중 팀이 선택) |
| **1차시** | 불편함 20개 찾기 | **경계 찾기** + 불편함 찾기 |
| **2차시** | 클래스 정하기 | 클래스 정하기 + **"누가 이 경계를 정했나"** |
| **6차시** | 성능 개선 | 성능 개선 + **"우리가 만든 경계 되돌아보기"** |
| **예제 파일** | 분리수거 (그대로) | **그대로 둡니다** — 아래 1.4 참조 |

## 1.4 예제 파일은 바꾸지 않습니다

혼동하기 쉬운 지점이라 분명히 해둡니다.

```
  ┌─────────────────────────┬──────────────────────────┐
  │   예제 파일 (교사의 것)     │    프로젝트 (아이들의 것)     │
  ├─────────────────────────┼──────────────────────────┤
  │  분리수거 도우미            │   팀이 스스로 고른 주제       │
  │  1~3차시 PRIMM 실습용      │   4~6차시 제작·테스트·개선    │
  │  구체적이고 좁아야 좋다      │   넓고 열려 있어야 좋다        │
  └─────────────────────────┴──────────────────────────┘
```

PRIMM의 예제는 **좁고 구체적일수록 좋습니다.** 무엇을 봐야 할지 분명해야 하니까요. 여백은 예제가 아니라 프로젝트에 있어야 합니다. `분리수거도우미_예제파일_제작가이드.md` 는 그대로 쓰시면 됩니다.

# 2. 세 가지 관점

이 수업에 들어올 세 개의 시선입니다. **아이들에게 이 용어를 가르치지 않습니다.** 교사가 알고 있으면 발문이 달라집니다.

## 2.1 사회학 — 분류에는 권력이 있다

```
   누가 범주를 정하는가?
   범주에 들어가지 못한 것은 어떻게 되는가?
```

분류는 중립적인 작업이 아닙니다. 무엇을 하나로 묶고 무엇을 나눌지 정하는 순간, 그 기준을 정한 사람의 관점이 세상에 새겨집니다. 학교는 아이를 학년으로 나누고, 도서관은 책을 분야로 나눕니다. 그 기준은 하늘에서 내려온 것이 아니라 누군가가 정한 것입니다.

**수업에서 만나는 지점**

- 2차시에서 클래스를 정할 때, 아이들은 **범주를 정하는 사람**이 됩니다. 이걸 의식하게 만드세요.
- '모르겠음' 클래스는 **분류에서 밀려난 것들의 자리**입니다. 여기에 무엇이 들어갔는지 목록을 만들면 사회학이 시작됩니다.
- 우리 AI가 잘 못 알아보는 대상은 **데이터에서 소외된 대상**입니다.

> **핵심 발문**
> "이 네 가지로 나눈 건 누구예요?"
> "'모르겠음' 통에 들어간 것들은 어떤 애들이죠?"
> "우리가 만든 이 규칙을 다른 반 친구도 똑같이 만들었을까요?"

## 2.2 심리학 — 사람도 범주로 생각한다

```
   우리는 왜 자꾸 나누는가?
   빠르게 나누면 무엇을 얻고 무엇을 잃는가?
```

사람의 머리는 세상을 하나하나 다 기억하지 않습니다. 묶어서 기억합니다. 처음 보는 물건도 "아, 컵 같은 거네" 하고 넘어갑니다. 이 능력 덕분에 우리는 빠르게 판단할 수 있습니다.

대신 대가가 있습니다. **고정관념**입니다. 몇 개를 보고 전체를 판단해 버리는 것. AI가 40장의 사진으로 세상 모든 페트병을 판단하는 것과 정확히 같은 구조입니다.

**수업에서 만나는 지점**

- 1차시 몸짓 스무고개에서 아이들은 **특징 몇 개로 전체를 맞힙니다.** 사람도 AI처럼 작동한다는 걸 몸으로 겪습니다.
- 5차시에서 AI가 창가에서 틀릴 때, 그것은 "적은 경험으로 판단해서"입니다. 사람도 똑같습니다.
- 6차시 개선은 "더 많은, 더 다양한 경험을 주는 일"입니다.

> **핵심 발문**
> "AI는 사진 40장 보고 다 안다고 생각했어요. 사람도 그런 적 있나요?"
> "처음 만난 친구를 몇 초 만에 판단해 본 적 있어요? 그게 맞았어요?"
> "AI가 틀린 이유랑, 사람이 오해하는 이유가 비슷한가요?"

## 2.3 철학 — 경계는 어디에 있는가

```
   어디부터가 A이고 어디부터가 B인가?
   그 선은 세상에 있는가, 우리가 그은 것인가?
```

가장 깊은 곳입니다. 그리고 초등 5학년이 놀랄 만큼 잘 다루는 영역입니다.

물이 컵에 얼마나 남아야 "비었다"입니까? 책상이 얼마나 어질러져야 "지저분하다"입니까? 답이 없습니다. 사람마다 다르고, 상황마다 다릅니다. **경계는 세상에 새겨져 있는 것이 아니라 우리가 긋는 것입니다.**

AI는 이 문제를 피할 수 없습니다. 반드시 어딘가에 선을 그어야 하니까요. 그리고 그 선을 긋는 사람이 이 수업에서는 아이들입니다.

**수업에서 만나는 지점**

- 1차시 **경계 찾기 활동**(3.1절)이 정면으로 이 질문을 다룹니다.
- 2차시 실험 B에서 "AI는 왜 모르겠다고 말하지 못하는가"가 나옵니다.
- 6차시 신뢰도 임계값(0.7? 0.9?)을 정하는 것은 **경계를 긋는 행위 그 자체**입니다.

> **핵심 발문**
> "어디부터가 '지저분한 책상'이에요? 세 명 다 다르네요. 누가 맞아요?"
> "AI한테는 누가 그 선을 정해줘요?"
> "0.7로 할까요 0.9로 할까요? 왜요?"

# 3. 주제 우산 — 5개 갈래

주제를 지정하지 않습니다. 대신 **갈래**를 보여주고 그 안에서 팀이 찾게 합니다.

```
              「우리는 무엇을 구분하며 살아가는가」
                            │
     ┌──────────┬──────────┼──────────┬──────────┐
     ▼          ▼          ▼          ▼          ▼
   ① 사물     ② 상태     ③ 몸짓     ④ 있다/없다  ⑤ 애매한 것
    무엇인가   어떻게     무엇을      거기 있나    어디부터인가
              되었나     말하나
   ────────  ────────  ────────  ────────  ────────
    쉬움       보통       보통       쉬움       어려움 ★
```

## 갈래 ① 사물 — "이건 무엇인가"

가장 진입하기 쉽습니다. 첫 프로젝트로 안전합니다.

| 예 | 구분할 것 |
|---|---|
| 분리수거 | 플라스틱 / 종이 / 캔 |
| 물건 제자리 찾기 | 가위 / 풀 / 자 |
| 과일 고르기 | 익은 것 / 덜 익은 것 |
| 우리 반 화분 | 물 준 흙 / 마른 흙 |

> **여백을 주는 발문** — "우리 교실에서 자꾸 헷갈리는 물건이 뭐예요?"

## 갈래 ② 상태 — "어떻게 되었나"

같은 물건이 시간에 따라 달라지는 것을 봅니다. **경계가 애매해지기 시작합니다.**

| 예 | 구분할 것 | 숨어 있는 질문 |
|---|---|---|
| 급식 잔반 | 다 먹음 / 남김 | 얼마나 남아야 "남긴" 건가 |
| 물통 확인 | 비었다 / 남았다 | 몇 %부터 "비었다"인가 |
| 창문 | 열림 / 닫힘 | 반쯤 열린 건? |
| 책상 정리 | 정리됨 / 어지러움 | **누가 정하나** |

> **여백을 주는 발문** — "우리 반에서 '다 했다 / 아직이다'를 자꾸 확인해야 하는 게 뭐예요?"

## 갈래 ③ 몸짓과 신호 — "무엇을 말하나"

심리학이 가장 자연스럽게 들어오는 갈래입니다.

| 예 | 구분할 것 |
|---|---|
| 우리 반 수신호 | 조용히 / 도와줘 / 다 했어요 |
| 바른 자세 알리미 | 바른 자세 / 굽은 자세 |
| 손 씻기 확인 | 씻는 중 / 그냥 물만 |
| 우리끼리 만든 암호 | 팀이 직접 정한 손동작 3종 |

> **여백을 주는 발문** — "말 안 하고 신호로 전하고 싶은 게 있어요?"

> **⚠ 반드시 지킬 것** — 사람을 대상으로 하는 주제는 **본인과 팀원의 몸짓·자세만** 다룹니다. 얼굴 생김새, 인종, 성별, 감정 상태를 분류하는 주제는 다루지 않습니다. 왜 그런지는 5.2절에 있습니다.

## 갈래 ④ 있다 / 없다 — "거기 있나"

가장 단순하지만 실생활 효용이 큽니다.

| 예 | 구분할 것 |
|---|---|
| 우산 두고 가지 마 | 우산 있음 / 없음 |
| 실내화 확인 | 실내화 / 운동화 |
| 자리 비움 알림 | 사람 있음 / 없음 |
| 급식 판 반납 | 반납함 / 안 함 |

> **여백을 주는 발문** — "자꾸 깜빡해서 곤란한 게 뭐예요?"

## 갈래 ⑤ 애매한 것 — "어디부터인가" ★

**이 수업의 하이라이트입니다.** 정답이 없는 것을 일부러 고르는 갈래입니다.

| 예 | 왜 어려운가 |
|---|---|
| 웃는 얼굴 / 안 웃는 얼굴 | 어디부터가 웃음인가 |
| 줄이 길다 / 짧다 | 몇 명부터 "길다"인가 |
| 깨끗하다 / 더럽다 | 누구 기준인가 |
| 다 먹었다 / 남겼다 | 한 숟갈은? |

이 갈래를 고른 팀에게는 미리 말해 주세요.

> "이건 답이 없는 문제예요. AI가 잘 맞히기 어려울 거예요. 그런데 **왜 어려운지 알아내는 것**이 여러분의 발명이 될 거예요."

성능이 낮아도 됩니다. 이 팀의 산출물은 정확도가 아니라 **"우리는 어디에 선을 그었고, 왜 그렇게 그었는가"** 라는 기록입니다.

> **교사 판단** — 세 명 팀이 자신 있어 보이면 ⑤를 권해 보세요. 6차시에서 가장 좋은 이야기가 나옵니다. 다만 첫 프로젝트이고 아이들이 위축되어 있다면 ①이나 ④가 안전합니다.

# 4. 차시 수정안

기존 6차시 구조는 유지하고, 세 지점만 바꿉니다.

## 4.1 1차시 — 경계 찾기 활동 추가

**활동 2를 30분에서 이렇게 재구성합니다.**

### ▸ 앞부분 (12분) — 어디부터가 그것인가

칠판에 세 문장을 씁니다. 각자 **혼자** 답을 적습니다. 상의 금지.

```
 ①  컵에 물이 얼마나 남아야  "비었다"  인가요?
     → 나의 답 : _______%

 ②  책상 위에 물건이 몇 개 있어야  "지저분하다"  인가요?
     → 나의 답 : _______개

 ③  줄이 몇 명부터  "길다"  인가요?
     → 나의 답 : _______명
```

셋의 답을 나란히 칠판에 적습니다. **반드시 다릅니다.**

> **발문 1** — "세 명이 다 다르네요. 누가 맞아요?"
> **발문 2** — "그럼 이 선은 어디 있는 거예요? 컵에 그어져 있어요?"
> **발문 3** — "아까 우리가 본 AI(1차시 완성 예제)한테는 **누가 이 선을 정해줬을까요?**"

마지막 발문의 답이 이 프로젝트 전체의 출발점입니다.

```
   ┌──────────────────────────────────────────┐
   │                                          │
   │      AI에게는 우리가 선을 그어 줍니다.        │
   │                                          │
   │      이번 프로젝트에서 그 선을 긋는 사람은     │
   │      바로 여러분입니다.                      │
   │                                          │
   └──────────────────────────────────────────┘
```

### ▸ 뒷부분 (18분) — 갈래에서 찾기

5개 갈래를 벽에 붙여 놓고, 팀이 돌아다니며 각 갈래마다 **우리 학교 이야기를 하나씩** 찾습니다. 5개를 채운 뒤 그중 하나를 고릅니다.

> **주의** — 3.1~3.5절의 예시 표를 아이들에게 **보여주지 마세요.** 갈래 이름과 한 줄 질문만 붙입니다. 예시를 보면 거기서 고르고 맙니다.

벽에 붙일 것은 이 다섯 장뿐입니다.

```
 ┌──────────────┐ ┌──────────────┐ ┌──────────────┐
 │   ① 사물      │ │   ② 상태      │ │   ③ 몸짓      │
 │              │ │              │ │              │
 │ "이건 무엇인가" │ │ "어떻게 되었나" │ │ "무엇을 말하나" │
 └──────────────┘ └──────────────┘ └──────────────┘
 ┌──────────────┐ ┌──────────────┐
 │  ④ 있다/없다   │ │  ⑤ 애매한 것   │
 │              │ │              │
 │ "거기 있나"    │ │ "어디부터인가"  │
 └──────────────┘ └──────────────┘
```

## 4.2 2차시 — 클래스 정할 때 한 질문 추가

클래스를 확정한 직후, 5분만 씁니다.

> **발문** — "이 네 가지로 나눈 건 누구예요?"
> **발문** — "옆 반 친구들이 같은 문제를 맡았으면 똑같이 나눴을까요?"
> **발문** — "다르게 나눌 수도 있었을까요? 어떻게요?"

다르게 나눌 수 있었던 방법을 **설계표 여백에 적어 두게** 합니다. 6차시에 다시 꺼냅니다.

## 4.3 6차시 — 개선 뒤에 되돌아보기 추가

개선 2·3회전을 마친 뒤, **닫는 활동 10분을 이렇게 바꿉니다.**

### ▸ '모르겠음' 통 열어보기

│                                                      │
│   ______________  ______________  ______________     │
│   ______________  ______________  ______________     │

│   아니면 우리가 관심 없었던 것인가요?                     │
│   ______________________________________________     │

이 질문 하나가 사회학·심리학·철학을 동시에 건드립니다. 답을 정리해 줄 필요는 없습니다. 아이들이 잠깐 멈추면 그것으로 충분합니다.

# 5. 교사용 유의

## 5.1 가르치지 말고 만나게 할 것

이 문서의 사회학·심리학·철학은 **교사가 알고 있어야 할 지도**이지 아이들에게 전달할 내용이 아닙니다.

```
   ✕  "이걸 사회학에서는 분류의 권력이라고 해요"
   ✕  "고정관념이라는 심리학 개념이 있는데요"
   ✕  "철학자들은 이걸 경계의 문제라고 부릅니다"

   ○  "이 네 가지로 나눈 건 누구예요?"
   ○  "처음 본 친구를 몇 초 만에 판단한 적 있어요?"
   ○  "세 명이 다 다르네요. 누가 맞아요?"
```

개념어를 꺼내는 순간 아이들은 답을 외우려 합니다. 질문만 던지고, **아이들이 어색하게 침묵하는 시간을 견디세요.** 5학년은 이 질문들에 놀라운 답을 내놓습니다.

## 5.2 사람을 분류하는 주제 — 하지 않습니다

갈래 ③에서 학생이 이런 주제를 가져올 수 있습니다.

```
   ✕  남자 / 여자 구분하기
   ✕  기분 좋은 친구 / 나쁜 친구 구분하기
   ✕  공부 잘하는 친구 알아보기
   ✕  우리 반 친구 얼굴 알아보기
```

**모두 하지 않습니다.** 이유를 아이들에게 이렇게 설명하세요.

> "사람을 사진 몇 장으로 나누면, 거기 안 맞는 사람은 어떻게 될까요? AI는 반드시 어느 한쪽으로 밀어 넣어요. 사람한테 그러면 안 돼요."

이것 자체가 훌륭한 수업 장면이 됩니다. 금지로 끝내지 말고 **왜 안 되는지를 함께 생각하는 5분**으로 쓰세요.

**허용되는 것** — 본인과 팀원이 **의도적으로 만든 신호**(손동작, 자세). 몸이 무엇을 하고 있는지이지, 그 사람이 어떤 사람인지가 아니기 때문입니다.

## 5.3 갈래 ⑤를 고른 팀 지원하기

성능이 낮게 나옵니다. 아이들이 실패했다고 느끼지 않게 하는 것이 교사의 일입니다.

- **미리 예고합니다** — "이건 원래 어려운 문제예요."
- **평가 기준을 바꿔 말해 줍니다** — "몇 개 맞혔는지가 아니라, 왜 어려운지 알아냈는지를 볼 거예요."
- **6차시에 먼저 발언 기회를 줍니다** — 이 팀의 이야기가 가장 흥미롭습니다.

## 5.4 여백이 너무 넓어 막힐 때

3인 팀이 30분 동안 아무것도 못 고르는 경우가 있습니다. 이때만 단계적으로 좁힙니다.

```
   1단계   "다섯 갈래 중에 어떤 게 제일 끌려요?"      → 갈래 선택
   2단계   "그 갈래에서 우리 학교 이야기 세 개만"      → 후보 3개
   3단계   "셋 중에 사진으로 찍을 수 있는 건?"        → 실현 가능성 필터
   4단계   그래도 못 고르면 → 예시 표 중 하나를 보여줌
```

4단계까지 가더라도 **예시를 그대로 쓰게 하지 말고 "여기서 뭘 바꾸면 우리 것이 될까?"** 를 물으세요.

# 6. 발문 모음

수업 중 꺼내 쓸 질문을 관점별로 모았습니다. 인쇄해 교탁에 두세요.

## 사회학 — 누가 정하는가

- 이 네 가지로 나눈 건 누구예요?
- 옆 반 친구가 같은 문제를 맡았으면 똑같이 나눴을까요?
- 다르게 나눌 수도 있었을까요?
- '모르겠음' 통에는 어떤 애들이 들어갔어요?
- 우리 발명품을 못 쓰는 사람은 누구일까요?
- 학교에서 우리를 나누는 기준에는 뭐가 있어요? 그건 누가 정했어요?

## 심리학 — 사람도 그런다

- AI는 사진 40장 보고 다 안다고 생각했어요. 사람도 그런 적 있어요?
- 처음 만난 친구를 몇 초 만에 판단해 본 적 있어요? 맞았어요?
- AI가 틀린 이유랑 사람이 오해하는 이유가 비슷한가요?
- 우리 AI는 왜 창가에서 틀렸을까요? 안 가본 곳이라 그런가요?
- 더 많이 보여주면 나아질까요? 사람도 그럴까요?

## 철학 — 선은 어디에

- 어디부터가 '비었다'예요?
- 세 명이 다 다르네요. 누가 맞아요?
- 그 선은 어디 있어요? 컵에 그어져 있어요?
- AI한테는 누가 그 선을 정해줘요?
- 0.7로 할까요 0.9로 할까요? 왜요?
- '모르겠음'은 AI가 몰라서일까요, 우리가 안 가르쳐서일까요?
- 완벽하게 나눌 수 있는 게 세상에 있을까요?
