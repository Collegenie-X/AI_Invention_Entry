### — 아이들의 "고민"에서 시작하는 발명 주제 —

---

## 이 문서의 사용법

> **1차시 활동 2(불편함 사냥)에서 팀이 스스로 주제를 찾는 것이 원칙입니다.**
> 이 카드는 **아이들이 막혔을 때만** 꺼냅니다. 먼저 보여주면 "고르는 수업"이 되고, 발견(①) 단계가 통째로 사라집니다.

**꺼내는 방법 — 카드를 주지 말고 '고민'만 읽어 주세요.**

10개 주제의 **고민 문장만** 소리 내어 읽어 주고, "이 중에 너희 얘기 같은 게 있어?"라고 묻습니다.
클래스·반응·코드는 팀이 정하게 둡니다. 그것이 2·3차시의 내용이기 때문입니다.

### 주제 선정 3가지 조건

| 조건 | 확인 질문 | 왜 |
|---|---|---|
| **① 구분 가능** | "무엇과 무엇을 구분하면 해결되나?" | 답 못 하면 이미지 분류로 만들 수 없음 |
| **② 촬영 가능** | "그 장면을 학교에서 30장 찍을 수 있나?" | 데이터가 없으면 4차시가 무너짐 |
| **③ 내 이야기** | "이거 너희가 진짜 겪은 일이야?" | 남의 문제는 6차시 개선까지 못 감 |

### 난이도 표시

| 표시 | 뜻 |
|---|---|
| ★☆☆ | 물건을 구분함 — 가장 안정적. 첫 프로젝트 권장 |
| ★★☆ | 사람의 자세·행동을 구분함 — 조명·거리 영향 큼 |
| ★★★ | 상태의 변화·정도를 구분함 — 실패가 많음. 대신 6차시가 풍부해짐 |

## 01. 쉬는 시간 종이 울려도 아무도 안 치워요 — **분리수거 짝꿍**

**★☆☆ · 물건 구분**

> ### 아이들의 고민
> "우리 반 쓰레기통에 자꾸 다 섞여 있어요. 저도 사실 우유팩을 어디에 넣는지 잘 몰라요. 물어보기는 창피하고요."

| 항목 | 내용 |
|---|---|
| **누가 불편한가** | 분리수거를 헷갈리는 학생 전부 · 매일 정리하는 주번 |
| **무엇과 무엇을 구분** | 플라스틱 / 종이 / 캔 / **모르겠음** |
| **마이크로비트 반응** | 해당 통 색 신호(하트·네모·삼각) + 안내음, '모르겠음'은 ✕ |
| **촬영 계획 힌트** | 실제 급식 후 쓰레기(찌그러진 것, 젖은 것)를 반드시 포함 |
| **예상 실패** | 찌그러진 페트병 · 라벨 뗀 병 · 손이 같이 찍힘 |

**캠페인으로 잇기** — 일주일간 옆에 두고 **"오늘 몇 번 도와줬나"** 카운트를 붙여 둡니다.
1주 뒤 쓰레기통 사진 전후 비교를 복도에 게시 → *「우리 반 분리수거 정확도 ○○%」*

## 02. 급식 남기는 게 미안한데 말은 못 해요 — **잔반 응원단**

**★★☆ · 상태 구분**

> ### 아이들의 고민
> "급식을 남기면 죄송한데, 억지로 먹으라는 것도 싫어요. 그냥 조금씩 줄이고 싶은데 아무도 안 알아줘요."

| 항목 | 내용 |
|---|---|
| **누가 불편한가** | 편식하는 학생 · 잔반량을 걱정하는 영양 선생님 |
| **무엇과 무엇을 구분** | 다 먹음 / 조금 남김 / 많이 남김 / **모르겠음** |
| **마이크로비트 반응** | 웃는 얼굴 → 보통 얼굴 → 슬픈 얼굴 (혼내지 않는 톤이 핵심) |
| **촬영 계획 힌트** | 식판을 위에서 같은 높이로. 국물·밥알 남은 상태도 찍기 |
| **예상 실패** | 식판 각도가 조금만 달라져도 무너짐 → 촬영 위치 표시 테이프 필수 |

> **교사 유의** — 개인을 지목하는 도구가 되지 않도록 **이름을 저장하지 않고, 반 전체 횟수만** 세게 하세요. 4차시에서 학생과 이 규칙을 함께 정하면 훌륭한 AI 윤리 수업이 됩니다.

**캠페인으로 잇기** — *「남기지 말자」가 아니라 「먹을 만큼만 받자」* 캠페인.
배식대 앞에 두고 **덜어내기 요청 스티커**와 연동.

## 03. 자꾸 등이 굽는데 저도 모르겠어요 — **거북목 알리미**

**★★☆ · 자세 구분**

> ### 아이들의 고민
> "공부하다 보면 어느새 얼굴이 책에 닿아 있어요. 엄마가 계속 말해도 그때뿐이에요. 제가 언제 굽는지 제가 몰라요."

| 항목 | 내용 |
|---|---|
| **누가 불편한가** | 본인 · 매번 잔소리해야 하는 부모·교사 |
| **무엇과 무엇을 구분** | 바른 자세 / 굽은 자세 / 자리 비움(**모르겠음** 역할) |
| **마이크로비트 반응** | 굽은 자세가 **연속 10초 이상**일 때만 짧은 진동음 1회 |
| **촬영 계획 힌트** | 같은 의자, 같은 옆모습 각도. 세 명 모두의 자세를 찍어야 일반화됨 |
| **예상 실패** | 옷 색이 바뀌면 오작동 · 뒤 배경에 사람이 지나가면 무너짐 |

> **설계 포인트** — 즉시 울리면 시끄러워서 아무도 안 씁니다. **"몇 초 이상 지속될 때만"** 이라는 조건을 학생이 직접 붙이게 하세요. 3차시 실험 D·E가 여기서 쓰입니다.

**캠페인으로 잇기** — 학급 **「1분 스트레칭 알림」** 으로 확장. 알림이 울리면 반 전체가 함께 일어나기.

## 04. 우산을 세 번이나 잃어버렸어요 — **현관 지킴이**

**★☆☆ · 물건 구분**

> ### 아이들의 고민
> "비 오는 날 아침에만 우산이 있고, 집에 갈 때는 항상 없어요. 학교 우산꽂이에는 주인 없는 우산이 스무 개나 있어요."

| 항목 | 내용 |
|---|---|
| **누가 불편한가** | 물건을 자주 두고 가는 학생 · 분실물함을 관리하는 선생님 |
| **무엇과 무엇을 구분** | 우산 들고 있음 / 안 들고 있음 / **모르겠음** |
| **마이크로비트 반응** | 우산 없이 지나가면 "잠깐!" 소리 + ✕ 표시 |
| **촬영 계획 힌트** | **비 오는 날에 찍는 것이 어려움** → 접힌 우산·펼친 우산·가방에 꽂힌 우산 모두 |
| **예상 실패** | 우산과 긴 자·막대기를 헷갈림 → '모르겠음'에 긴 물건을 넣어야 함 |

**캠페인으로 잇기** — **분실물 제로 주간.** 교실 뒷문에 설치하고 하교 시간에만 작동.
분실물함 사진을 매일 찍어 개수 그래프를 그립니다.

## 05. 손 씻으라는 말은 많은데 아무도 안 봐요 — **손 씻기 응원 로봇**

**★★☆ · 행동 구분**

> ### 아이들의 고민
> "급식 전에 손 씻으라고 하는데, 물만 묻히고 오는 애들이 많아요. 저도 가끔 그래요. 시간을 재라는데 세기 귀찮아요."

| 항목 | 내용 |
|---|---|
| **누가 불편한가** | 위생이 걱정되는 학생 전부 · 보건 선생님 |
| **무엇과 무엇을 구분** | 비누 거품 손 / 그냥 젖은 손 / 손 없음(**모르겠음**) |
| **마이크로비트 반응** | 거품 감지 시 **20초 카운트 LED** → 끝나면 하트 + 축하음 |
| **촬영 계획 힌트** | 세면대 위 고정 각도. 거품 양이 많은 것/적은 것 모두 |
| **예상 실패** | 물이 튀어 렌즈가 흐려짐 → 하드웨어 개선(방수 커버)이 6차시 소재 |

**캠페인으로 잇기** — **20초 챌린지.** 20초 카운트에 맞춘 노래를 팀이 직접 골라 마이크로비트로 연주.
반별 성공 횟수를 붙여 대결.

## 06. 복도에서 뛰다가 부딪혀서 다쳤어요 — **모퉁이 안전 눈**

**★★☆ · 행동 구분**

> ### 아이들의 고민
> "복도 모퉁이에서 반대편이 안 보여요. 지난주에 3학년 동생이랑 세게 부딪혔어요. '뛰지 마'라는 종이는 붙어 있는데 아무도 안 봐요."

| 항목 | 내용 |
|---|---|
| **누가 불편한가** | 부딪힌 경험이 있는 학생 · 안전 지도하는 선생님 |
| **무엇과 무엇을 구분** | 걷는 사람 / 뛰는 사람 / 아무도 없음(**모르겠음**) |
| **마이크로비트 반응** | 뛰는 자세 감지 → 노란 경고 패턴 + 짧은 알림음 |
| **촬영 계획 힌트** | 걷기·뛰기를 팀원이 직접 연기. **여러 사람의 여러 속도**로 |
| **예상 실패** | 순간 자세라 흐릿하게 찍힘 · 뛰는 것과 팔 흔드는 것을 구분 못 함 |

> **설계 포인트** — "뛴다"는 **한 장의 사진으로 판별하기 가장 어려운 것** 중 하나입니다. 실패가 많이 나옵니다. 그래서 6차시 개선 수업으로는 최고의 재료입니다. 팀이 도전 의지가 있을 때 권하세요.

**캠페인으로 잇기** — **「걸어 다니는 우리 학교」** 주간. 경고음이 하루에 몇 번 울렸는지 매일 게시.
숫자가 줄어드는 걸 보는 것이 캠페인 그 자체.

## 07. 우리 반 화분이 또 말라 죽었어요 — **식물 돌보미**

**★★★ · 정도 구분**

> ### 아이들의 고민
> "당번이 돌아가면서 물을 주는데, 어떤 날은 두 번 주고 어떤 날은 아무도 안 줘요. 지난번 방울토마토는 그렇게 죽었어요."

| 항목 | 내용 |
|---|---|
| **누가 불편한가** | 화분 당번 · 식물 |
| **무엇과 무엇을 구분** | 잎이 싱싱함 / 잎이 처짐 / **모르겠음** (+ 흙 색으로 확장 가능) |
| **마이크로비트 반응** | 처짐 감지 → 물방울 모양 LED, 싱싱하면 하트 |
| **촬영 계획 힌트** | **시간이 필요합니다.** 1차시부터 매일 같은 시각·같은 각도로 찍어 두기 |
| **예상 실패** | 처진 상태 사진이 부족함 → 물 안 준 화분을 미리 준비해야 함 |

> **교사 준비** — 이 주제를 고를 것 같으면 **수업 2주 전부터 잘 키운 화분과 물 안 준 화분을 따로 준비**하세요. 데이터가 없으면 진행 자체가 불가능합니다.

**캠페인으로 잇기** — 교실 창가 **「초록이 살리기」** 프로젝트. 마이크로비트 밝기 센서(3차시 실험 F)를 붙여 햇빛 부족까지 알림.

## 08. 실내화를 안 신고 들어와서 교실이 더러워요 — **신발 검문소**

**★☆☆ · 물건 구분**

> ### 아이들의 고민
> "비 오는 날 운동화 그대로 들어오는 애들 때문에 교실 바닥이 엉망이에요. 청소는 우리가 하는데요."

| 항목 | 내용 |
|---|---|
| **누가 불편한가** | 청소 당번 · 바닥에 앉아 활동하는 학생 전부 |
| **무엇과 무엇을 구분** | 실내화 / 운동화 / 맨발·양말(**모르겠음**) |
| **마이크로비트 반응** | 실내화 ✓ + 밝은 음 / 운동화 ✕ + 낮은 음 |
| **촬영 계획 힌트** | 교실 입구 바닥 높이. 여러 사람의 여러 신발을 반드시 섞기 |
| **예상 실패** | 자기 팀 신발만 찍어 학습 → 다른 반 친구가 오면 무너짐 |

> **설계 포인트** — 이 주제는 **"우리 것만 찍으면 안 된다"** 는 데이터 편향을 가장 쉽게 체감시킵니다. 4차시 촬영 지도의 좋은 사례입니다.

**캠페인으로 잇기** — **깨끗한 교실 바닥 챌린지.** 아침 등교 시간에만 작동시키고, 통과율을 주간 그래프로.

## 09. 게시판에 붙인 안내문을 아무도 안 봐요 — **지나가면 말 거는 게시판**

**★☆☆ · 물건/사람 구분** · *캠페인 특화*

> ### 아이들의 고민
> "우리가 만든 캠페인 포스터를 복도에 붙였는데 아무도 안 멈춰요. 열심히 그렸는데 속상해요."

| 항목 | 내용 |
|---|---|
| **누가 불편한가** | 캠페인을 준비한 학생 · 안내가 전달 안 되는 모두 |
| **무엇과 무엇을 구분** | 사람이 멈춰 섬 / 그냥 지나감 / 아무도 없음(**모르겠음**) |
| **마이크로비트 반응** | 멈추면 LED 메시지 흐르기 + 환영음 / 지나가면 조용히 반짝 |
| **촬영 계획 힌트** | 게시판 앞 정면. 서 있는 사람 / 걸어가는 사람 / 빈 복도 |
| **예상 실패** | 멀리 있는 사람도 '멈춤'으로 인식 → 거리 조건을 어떻게 넣을지가 개선 과제 |

> **왜 좋은 주제인가** — 발명품 자체가 **캠페인의 도구**입니다. 다른 주제와 결합하기 쉬워서, 팀이 두 가지를 하고 싶어 할 때 좋은 절충안이 됩니다.

**캠페인으로 잇기** — 어떤 캠페인이든 붙일 수 있음. 학교 자율 캠페인(독서·안전·환경) 주간에 대여.

## 10. 물통을 가져오고도 안 마셔요 — **물 마시기 알리미**

**★★★ · 정도 구분**

> ### 아이들의 고민
> "하교할 때 보면 아침에 채운 물이 그대로예요. 목마른 줄도 몰랐어요. 두통이 생긴 날이 많아요."

| 항목 | 내용 |
|---|---|
| **누가 불편한가** | 본인 · 수분 부족으로 힘들어하는 학생 |

| **마이크로비트 반응** | 가득 → "한 모금 어때요?" ✕ / 절반 → 보통 / 빈 통 → 하트 + 축하음 |
| **촬영 계획 힌트** | 책상 위 고정 위치. **투명 물통이 배경을 비추므로 배경을 두 곳 이상** |

> **설계 포인트** — "투명한 것은 카메라로 보기 어렵다"는 발견 자체가 훌륭한 배움입니다. 실패해도 성공한 수업입니다.
